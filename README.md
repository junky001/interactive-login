# 🔐 Interactive Login

A modern, interactive login and registration interface built with HTML, CSS, and JavaScript. The project focuses on creating a clean, user-friendly authentication experience with engaging visual interactions and responsive design.

## ✨ Features

- **Modern UI:** Clean and attractive user interface.
- **Interactive Login:** Engaging login experience.
- **User Registration:** Dedicated sign-up interface.
- **Responsive Design:** Designed to work across different screen sizes.
- **Interactive Elements:** JavaScript-powered buttons and interface interactions.
- **Smooth Animations:** Enhanced visual experience.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/junky001/interactive-login.git
```

### 2. Navigate to the project folder

```bash
cd interactive-login
```

### 3. Run the project

Open `login.html` in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code.
